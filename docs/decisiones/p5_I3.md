# P5 I3 — Plan semanal, cadenas y calculadora laboral

Fecha: 03-10-2026. Implementación exclusivamente de backend, sin GUI.

## Archivos
- Nuevos: `backend/ganttier/reports/weekly_roster.py`, `backend/ganttier/tools.py`.
- Router: `backend/ganttier/api/tools.py`; registrado al final de `api/__init__.py`.

## P5-01
- `GET /api/projects/{pid}/reports/weekly-roster?week_start=AAAA-MM-DD`.
- Normaliza al lunes y devuelve `plan_semanal_AAAA-MM-DD.xlsx` con MIME de Excel.
- Hoja Plan semanal: ID/nombre, lunes–domingo, cuadrillas y tareas sin trabajador nominal.
- Calendario efectivo: actividad/recurso → proyecto → predeterminado existente del núcleo.
- Fechas: planned_start/planned_finish, con respaldo early_* por extremo.
- Incluye actividades comenzadas antes; no asigna trabajadores por habilidad.
- Un descanso del recurso agrega `(no disponible)` sin ocultar la tarea.
- Detalle conserva ID de recurso/asignación y una fila por asignación/día laborable.
- HH explícitas repartidas uniformemente sobre todo el intervalo laborable de la actividad.
- Con work_hours=0 se respeta Assignment: units × horas del calendario de actividad por día.
- Incluye demandas genéricas y cuadrillas en Detalle, identificando el tipo de recurso.
- Máximo 250 trabajadores nominales y 1.000 actividades del intervalo; exceso → 422.
- Fechas Excel dd-mm-aaaa, filtros, cabeceras de impresión, ajuste de columnas y pie de extracción.
- La exportación solo lee; no afirma secuencia horaria, HH reales ni factibilidad intradía.

## P5-09
- `POST /api/projects/{pid}/relations/chain`, opcional `?dry_run=true`.
- Cuerpo: groups (listas ordenadas de códigos), type (FS/SS/FF/SF), lag_days entero.
- Solo modo proyecto, hasta 250 entradas; cada grupo contiene al menos dos códigos.
- Pares repetidos dentro del lote se cuentan una vez; grupos no se conectan entre sí.
- Devuelve created, existing y relations; en vista previa los vínculos nuevos tienen id=null.
- Aplicación con repo.transaction(immediate=True) y una llamada a repo.create_many.
- Códigos ausentes, vínculos distintos y ciclos rechazan todo el lote con 422.
- Vista previa usa _validate_relation_cycles con una lectura de aristas existentes + propuestas.
- El adaptador depende del SELECT actual del validador; una prueba verifica este contrato.
- No inserta temporalmente ni escribe durante la vista previa; no ejecuta CPM.

## P5-08
- `GET /api/calendars/{cid}/workdays?start=AAAA-MM-DD&days=N`.
- `GET /api/calendars/{cid}/workdays/between?start=AAAA-MM-DD&end=AAAA-MM-DD`.
- Resultado incluye calendario, regla inclusiva, días, horas y excluded (date/reason/kind).
- N=0 conserva la fecha; N<0 cuenta desde el inicio hacia atrás inclusivamente.
- Usa WorkCalendar para días, horas, feriados, excepciones y descansos NxM.
- Un intervalo invertido se rechaza con 422; las consultas no escriben.
